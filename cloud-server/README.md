# cloud-server

把本地网页游戏临时开个服务器，手机 / 平板 / 其他电脑输"链接 + 6 位访问码"就能玩。Windows 上用，不需要装任何东西。

**本目录不含游戏文件**。自己把网页游戏文件夹（index.html + 资源）放进 `game\` 目录，游戏版权归原作者，放你合法获取的内容。

## 文件

- `itch-server.cs` / `geturl.cs` — 服务器和取址源码（C#）
- `itch-server.exe` — 本地游戏服务器（Windows 自带 .NET）
- `itch-urlgetter.exe` — 自动抓隧道地址
- `一键启动.bat` — 双击一键启动
- `cloudflared.exe` — Cloudflare 官方隧道工具（Apache-2.0，Releases 里有，也可自己下载）

## 用法

1. 游戏文件放进 `game\`；
2. 双击 `一键启动.bat`，等它生成链接（约 30~60 秒）和 6 位访问码（每次随机）；
3. 任何设备浏览器打开链接、输访问码，玩；
4. bat 窗口按任意键 = 停止（直接关窗口也行）。

## 其他

- 想要固定访问码：编辑 `一键启动.bat`，把 `itch-server.exe 62814 %PWD%` 里的 `%PWD%` 改成你自己的固定码；
- 首次打开慢是正常的，要加载完整游戏文件，之后有缓存会快；
- 链接和访问码别公开传播，服务器停了链接就失效；
- 提示"找不到 py/python"就忽略，不需要 python。
