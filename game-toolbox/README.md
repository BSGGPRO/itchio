# game-toolbox

itch.io 游戏启动器，Windows 免安装单文件。基于 [Wal33D/itchio-downloader](https://github.com/Wal33D/itchio-downloader)（ISC License）改的，不用装 Node.js。

两种玩法：

- **本地玩**：本机浏览器直接开；
- **手机玩**：局域网模式，手机 / 平板连同一个 Wi-Fi，浏览器输地址就能玩。

## 用法

1. 双击 exe，浏览器自动打开界面；
2. 自动列出"下载\itch-games"里已下载的游戏（也能手动填目录点【扫描】）；
3. 每个游戏两个按钮：【本地玩】 / 【手机玩】，手机玩会显示局域网地址；
4. 游戏文件夹也可以直接拖到 exe 图标上启动。

## 手机玩注意

- 手机和电脑要连同一个 Wi-Fi；
- 地址会自动选真实网卡（不会选到加速器 / 云电脑的虚拟网卡），多网卡连不上就挨个试备选地址；
- 第一次连不上：Windows 防火墙弹窗选"允许"；
- iPhone / iPad：普通网页游戏都能玩，**Unity 3D 大游戏在苹果浏览器上跑不了**（苹果限制），这种用 Moonlight / Steam Link / ToDesk / 向日葵串流到手机玩。

## 免安装

整个文件夹拷到另一台 Windows 10 / 11（64 位）电脑直接能用，不需要装运行库。

## 使用政策

只用于已下载的公开 / 免费 / 已购买内容，遵守 itch.io 和游戏作者的规则。
